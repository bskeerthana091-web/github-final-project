
# Simple Interest Calculator

## About the Project

This project is a simple Bash-based calculator that calculates Simple Interest based on the Principal Amount, Rate of Interest, and Time Period entered by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal Amount
- Rate of Interest
- Time Period (in years)

## How to Run

1. Clone the repository.
2. Open the terminal.
3. Run the following command:

   bash simple-interest.sh

4. Enter the required values.
5. View the calculated Simple Interest and Total Amount.

## Technologies Used

- Bash Shell Scripting
- Linux Command Line
